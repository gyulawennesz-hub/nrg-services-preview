# NRG Services Kft. – weboldal prototípus

## Tartalom
- `index.html` – kezdőlap
- `szolgaltatasok.html` – szolgáltatások
- `referenciak.html` – referenciák
- `rolunk.html` – bemutatkozás
- `kapcsolat.html` – kapcsolat
- `szerkeszto.html` – egyszerű vizuális tartalomszerkesztő
- `styles.css`, `app.js`, `editor.js`, `content.js` – stílusok, működés és tartalom

## Helyi megtekintés
Nyisd meg az `index.html` fájlt böngészőben. Az online Google Fonts és Unsplash hero-fotó internetkapcsolatot igényel.

## Feltöltés Renderre
1. Csomagold ki a ZIP-et.
2. GitHub repository: `gyulawennesz-hub/nrg-services-preview`
3. `Add file` → `Upload files`.
4. Töltsd fel az összes fájlt a repository gyökérkönyvtárába, felülírva a régi `index.html`-t.
5. `Commit changes`.
6. A Render automatikusan újratelepíti a statikus oldalt.

Render beállítás: Publish Directory = `.`, Build Command üres.

## Vizuális szerkesztő
Nyisd meg a publikált oldalon a `szerkeszto.html` címet. A mezők átírása után töltsd le a `content.js` fájlt, majd töltsd fel GitHubra a meglévő `content.js` helyére és commitold. A Render ezután frissít.

**Megjegyzés:** ez egy egyszerű, statikus prototípus-szerkesztő. Nem rendelkezik felhasználói beléptetéssel vagy közvetlen szerveroldali mentéssel. A kapcsolatfelvételi űrlap e-mailt készít elő a látogató levelezőprogramjában; éles használat előtt adatkezelési tájékoztató, hozzájárulás és tényleges űrlapfeldolgozás szükséges.
